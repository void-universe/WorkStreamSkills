# 广告导演手册

一份可复用的广告分镜规矩：怎么做 3 秒一镜的短视频，怎么让跨镜头长得像同一支片子，怎么交付给渲染器。

## 分工

一支片子通常由四个人接力，各交一份文件：

- **导演**：一句话主张 + 观众 + 前 3 秒钩子 + 情绪曲线 + 风格锁。拍板。
- **场景规划**：2~3 个空间（地点 / 光线来源 / 主色 / 材质 / 空间关系）+ 可复用的英文环境描述。
- **剧情编导**：节拍表（钩子 / 问题 / 角色 / 动作 / 证明 / 落点）+ 旁白或对白 + CTA。
- **分镜**：把所有东西落成一份可渲染的分镜 JSON，交给渲染器。

人少的时候一个人全干也行，但这四份产出的边界仍然成立。

## 硬约束

- 一条镜头 **3 秒**（24fps，`length: 73`）。想更长就加条数，不要在一条里塞两个时刻。
- 草稿 **768×432**，定稿 **1280×720**；宽高必须能被 16 整除。
- **提示词必须英文**（主流视频模型对英文最稳）。
- 每条一个**连续瞬间**、一个**明确的运镜动词**（push-in / pull-out / side track / slow orbit / locked-off）。
- 视频模型**不会写字**：画面里的文字一律糊。需要文案就后期加，提示词里写 `no text`。

## 提示词骨架

```
[风格锁] + 主体与动作 + 环境与光 + 一个运镜 + 质感 + Audio: ... + No text / no watermark
```

- **风格锁**：30~50 词的固定描述（介质 / 镜头 / 色温 / 颗粒 / 影调），**每一条逐字复用**。这是跨镜头一致性的唯一杠杆。
- 抽象词翻成可观察事实：不写「高级、震撼、电影感」，写「浅景深、侧逆光、35mm、颗粒、慢速横移」。
- 音频写在最后一行：`Audio: 具体的声音`。它和画面一起生成，不是后期配。
- 负面固定带 `no text, no watermark, no subtitles`；拍实拍质感再加 `no illustration, no flat vector art`。

## 一致性

1. 风格锁逐字相同，别每条重写。
2. 同一空间用同一段环境描述。
3. 角色用同一串固定描述（发型、服装、体型、特征），**逐字复用**。
4. 一次只改一个变量（换运镜就别同时改光）。

## 品牌卡（由投放方决定）

片头、落点这类品牌卡不要交给视频模型画：标题、logo、网址它都写不对。用本地渲染（HTML/CSS 截帧或剪辑软件）合成，色系与片子对齐。

三条通用做法：

- 片头只放**一个主体**（标志或片名），停留 2~4 秒，比正片镜头更长。
- 落点卡写清三件事：产品名、一句话定位、一个可执行的入口（网址或动作）。
- 需要层级时（组织 / 产品）在落点卡上写一行归属，例如 `A PROJECT OF <组织>`，别在片头就解释。

## 交付

分镜交给渲染器，交付物的格式由渲染器定（通常是群文件或仓库里的一份 JSON）。渲染器回执里会列出每条的文件名、分辨率、耗时与状态；某条不合格就**只重跑那一条**，不要整片重渲。

## 边界

- 不用真人肖像、品牌 logo、版权角色当主体。
- 不要声称已渲染；证据是渲染回执。
- 生成内容可能有许可与地域限制，商用前自行确认。
